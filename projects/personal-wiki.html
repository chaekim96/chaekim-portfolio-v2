Asking my own notes questions, with no internet.

A study wiki for my AI course that never touches the cloud. Local Gemma, through Ollama, turns sources into linked Obsidian notes. An ask command answers from those notes with citations, or says the evidence isn't there.

The problem

Cloud assistants answer confidently from anywhere. For studying I wanted the opposite: answers only from my own sources, a citation for every claim, on a laptop with Wi-Fi off.

Product requirements

  • Ingest my course sources into linked Obsidian notes and answer study questions from those sources with citations.
  • Run entirely on the laptop after setup, with no cloud calls or hosted embeddings, within the machine's available memory.
  • Keep ask, chat, and search behavior separate; unsupported questions should return insufficient evidence.
  • Preserve hand-edited notes and source links when ingesting the same material again.

What I did

  • Picked the model to fit the machine. Gemma 4 E2B at 4-bit, because the larger versions didn't fit in the 5 to 6 GB free on an 18 GB Mac.
  • Wrote the CLI and harness with only Python's standard library: ingest, search, ask, and chat modes.
  • Built hybrid retrieval: my own BM25 plus local embeddings, merged with reciprocal rank fusion.
  • Wrote the expected answers for four tests before running them, including one the wiki should refuse.
  • Checked ask-mode citations against the retrieved passages in code and flagged invalid answers. Chat has a separate citation check with one retry.
  • Recorded an offline demo with Wi-Fi off. All four tests matched the online results.

The failure is documented. A question in my own shorthand ("A3") missed the right passage, and the model answered a nearby question with a real citation.

Milestones and next steps

  • Built: local ingestion, linked notes, hybrid search, cited answers, and a separate study-partner chat mode.
  • Evaluated: four prewritten ask tests, mode-separation checks, memory and response-time measurements, and an offline demonstration. Three of four ask tests passed.
  • Proposed, not implemented: expand aliases such as A3, reserve retrieval space across sources, and add an answer-relevance check. Re-run the original tests and retain the baseline for comparison.

Iterations and decisions

  • Keyword search to hybrid retrieval: adding local embeddings moved the paraphrase test's relevant passages from ranks 5 and 4 to ranks 2 and 3.
  • Reliable ingestion: save a plan for each source and detect hand edits, so repeated ingestion reuses note names and keeps edited notes.
  • Citations to relevance: the A3 test exposed a real citation attached to the wrong answer. The next experiment must check whether the evidence answers the actual question, as well as whether the citation exists.

What I'd do differently

Write more questions in my own shorthand before tuning retrieval. A citation check proves a citation exists, not that it answers the question; the failed A3 test made that distinction concrete.
