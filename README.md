# Chae Kim's portfolio

Static site for Chae Kim: MBA candidate at UC Berkeley Haas, ex-EY AI & Data consultant, IU Informatics. Plain HTML, generated by Python scripts and committed, then served by Vercel with no build step on its side (`vercel.json` enables clean URLs, so `/projects/luc` serves `projects/luc.html`).

## Working on it

```bash
python3 scripts/build.py           # write every page; commit the result
python3 scripts/build.py --check   # write nothing; fail if a page is out of date or unfinished
python3 -m http.server 8080        # preview at localhost:8080; project links need .html here, or use: npx serve .
```

`--check` also runs on every pull request. Edit the sources in `scripts/`, never the generated HTML.

## Where things live

| To change | Edit |
| --- | --- |
| A project's card, case study, live link or mark | `scripts/projects/<slug>.py` |
| Which folder a project is in, and the order | `scripts/projects/__init__.py` |
| The rest of the home page (intro, About, design notes) | `scripts/home.html` |
| A hand-written page (the college projects, Home GIF, Yin Yang, personal brand, build marks, tech pack, Siri, 404) | `scripts/pages/<name>.html` |
| Essays and the reading list | `scripts/writing_data.py`, `scripts/writing/` |
| The decision log | `scripts/build-decisions.py` |
| The "how this site was built" page | `scripts/build-portfolio.py` |
| Shared header, footer, head tags, name mark, site address (`SITE_URL`) | `scripts/stamp_shared.py` |
| Design tokens and the home page | `assets/css/v-stamp.css` |
| Project pages | `assets/css/case-stamp.css` (on top of `v-stamp.css`) |
| Liquid glass | `assets/js/liquid-glass.js`, rules at the end of `v-stamp.css` |
| Theme toggle, reveals, email | `assets/js/main.js` |

Stylesheets and scripts are linked with a hash of their contents, so there are no versions to bump. Images are cached forever: a changed image needs a new filename.

## Adding a project

1. Write `scripts/projects/<slug>.py`. Its `PROJECT` dict is described at the top of `scripts/projects/__init__.py`; copy a similar project. Any `kicker` means it gets a generated case page.
2. Add the slug to the right list in `scripts/projects/__init__.py`. A file that isn't listed, or a slug with no file, stops the build.
3. Add the page to `sitemap.xml` if it has one, then run `python3 scripts/build.py`.

## Other notes

- Images aren't part of `build.py`. Run `build-brand-cards.py` or `build-mod-covers.py` (headless Chrome), `build-resume.py` or `make-og.sh` when a mark, cover or the resume changes.
- Anything in `drafts/` or `scripts/` is not deployed. Everything else in the repo is public.
- Email is assembled at runtime from `data-user` / `data-domain` attributes (see `main.js`) so it isn't in the HTML.
- Resume: replace `assets/pdf/chae-kim-resume.pdf`. Every resume link already points there.
- Analytics: `/_vercel/insights/script.js` is included; enable Web Analytics in the Vercel dashboard for it to record.
